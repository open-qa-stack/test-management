# @open-qa-stack/testing

Helpers for the tests of the other packages: a guard that keeps every test on the loopback interface, a scripted model server, a local test site, a closed port, the lines a run writes to its journal, its traces and its inbox, and, under `@open-qa-stack/testing/test-repository`, what the tests of a run share whatever hosts the engine: a test repository, the replies of a model scripted for the whole chain, and the doubles of npm and Playwright. `@open-qa-stack/testing/fixture-repository` gives the same repository, replies and doubles to the tests another test runner starts, which say where the repository is made and what it targets.
