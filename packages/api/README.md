# @open-qa-stack/api

The back end of an instance, and the process of it that stays: a NestJS application on the Fastify adapter that says the operations on sessions of [`@open-qa-stack/engine`](../engine/docs/engine.md#the-operations-on-sessions) in HTTP. It serves the project and the sessions of the agents, with the events of each session as a stream, takes the sessions and the messages a person sends, and runs the sessions in the test repository it is given — see [docs/sessions.md](docs/sessions.md). It keeps its state in one database, a SQLite file in the test repository unless it is given the URL of another, which it reaches through `@open-qa-stack/store`, and which the `oqas` command reaches too: each shows the sessions of the other — see [docs/running.md](docs/running.md) and [the database](../store/docs/database.md).
